# 💰 MERN Expense Tracker

A full-stack **Expense Tracker Application** built using **MongoDB, Express, React, and Node.js**.  
Users can manage income & expenses, view transaction history, and analyze spending with charts.

---

## 🚀 Features

- User Signup & Login (JWT Auth)
- Add Income & Expense Transactions
- Delete Transactions
- Expense Analytics with Pie Chart
- Full Transaction History
- Responsive UI for Mobile & Desktop

---

## 🛠 Tech Stack

### Frontend:
- React.js
- Vite
- Recharts
- CSS

### Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication
